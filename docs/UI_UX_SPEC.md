# UI/UX 设计规范 (UI/UX Design Specification)

> 对标 **DataGrip、TablePlus、Supabase Table Editor、Prisma Studio、DBeaver** 等成熟 SQL 数据表格管理工具的 UI 质感与操作直觉。

---

## 1. 全局布局架构 (Global Layout)

采用经典的「三栏 + 工具栏 + 状态栏」IDE 级布局，所有面板均可折叠，核心数据表格始终占据最大视觉面积：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  顶部工具栏 (Toolbar)                                                        │
│  [文件名 ▾]  [🔍 全局搜索]  [筛选条件标签...]  [导出 ▾]  [设置 ⚙]  [主题 🌗] │
├──────────┬──────────────────────────────────────────────┬───────────────────┤
│          │  列头 (Sticky Header)                         │                   │
│  左侧栏  │  ┌────┬────────┬────────┬───────┬────────┐   │   右侧详情抽屉    │
│ (Schema  │  │ #  │ col_A  │ col_B  │ col_C │ col_D  │   │   (Row Detail     │
│  Panel)  │  ├────┼────────┼────────┼───────┼────────┤   │    Drawer)        │
│          │  │ 1  │ val    │ val    │ null  │ val    │   │                   │
│ □ col_A  │  │ 2  │ val    │ val    │ val   │ val    │   │  JSON Tree View   │
│ ☑ col_B  │  │ 3  │ ...    │ ...    │ ...   │ ...    │   │  ──────────────   │
│ ☑ col_C  │  │    │        │        │       │        │   │  {                │
│ □ col_D  │  │  ↕ 虚拟滚动区域 (仅渲染可视行)        │   │    "id": 1,      │
│          │  │    │        │        │       │        │   │    "name": "...", │
│ ─────── │  │ N  │ val    │ val    │ val   │ val    │   │    "meta": {      │
│ 排序:    │  └────┴────────┴────────┴───────┴────────┘   │      ...         │
│ A ↑ ↓    │                                              │    }             │
│          │                                              │  }               │
│          │                                              │  [复制] [格式化]  │
├──────────┴──────────────────────────────────────────────┴───────────────────┤
│  底部状态栏 (Status Bar)                                                      │
│  共 1,234,567 行  │  已筛选: 89,012 行  │  当前页: 1/890  │  加载: 0.2s      │
│  ← 1 2 3 ... 890 →  │  每页: [100 ▾]  │  选中: 第 42 行  │  内存: ~45MB     │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.1 布局规则

| 区域 | 默认状态 | 行为 |
|------|---------|------|
| **顶部工具栏** | 始终可见，高度 48px | 固定于视口顶部 (sticky)，包含文件信息、全局搜索、操作按钮 |
| **左侧 Schema 面板** | 默认展开，宽度 240px | 可折叠至图标模式 (48px)；展示全量字段列表与排序状态 |
| **主数据表格区** | 始终可见，弹性填满剩余空间 | 表头 sticky 固定，内容区虚拟滚动 |
| **右侧详情抽屉** | 默认隐藏 | 点击行时从右侧滑入，宽度 400px，支持 Esc 关闭 |
| **底部状态栏** | 始终可见，高度 32px | 固定于视口底部，展示统计信息与分页控件 |

| 元素 | 字体 | 字号 | 字重 |
|------|------|------|------|
| 表格单元格数据 | `JetBrains Mono` / `Menlo` / `monospace` | 13px | Regular (400) |
| 表头文字 | `Inter` / `system-ui` | 13px | Semibold (600) |

> **核心原则：** 数据区一律使用等宽字体 (Monospace)，确保数字、代码等内容的列对齐与可读性，这是 DataGrip / TablePlus 等专业工具的通用做法。

|------|------|

| 表头高度 | 36px |
| 单元格内边距 | 水平 12px，垂直 4px |
| 列最小宽度 | 80px |
| 列默认宽度 | 160px (自适应内容时上限 400px) |
| 左侧栏宽度 | 240px (可拖拽调整为 180-360px) |
| 右侧抽屉宽度 | 400px (可拖拽调整为 320-600px) |

| 网格线宽度 | 1px (实线) |

### 2.4 图标与组件风格

* **图标库：** 采用 [Lucide Icons](https://lucide.dev/)（轻量、线条风格，与 Tailwind 生态一致）。
* **按钮风格：** Ghost（幽灵/透明）为主，Hover 时出现浅色背景；主要操作使用 Fill 强调色按钮。
* **输入框：** 无边框或 1px 细边框，Focus 时显示主色描边 + 微弱阴影。
* **下拉菜单：** 无阴影或极轻阴影 (`shadow-sm`)，圆角 6px。
* **整体风格关键词：** *Minimal, Flat, Dense-Information, Developer-Tool Aesthetic*。

## 3. 数据表格网格详细规范 (Data Grid Specification)

### 3.1 表头 (Column Header)

表头是对标 SQL 管理器的核心交互区域，每列表头包含：

```
┌──────────────────────────┐
│  ↕  字段名称           ▾  │
│     (排序箭头)    (菜单)  │
└──────────────────────────┘
```

* **字段名：** 等宽字体显示，过长时截断并以 Tooltip 展示全名。
* **排序指示器：** 点击表头切换 `ASC ↑` → `DESC ↓` → `取消排序`，三态循环。当前排序列高亮且显示箭头图标。
* **列菜单 (Column Menu)：** 点击表头右侧 `▾` 图标弹出下拉菜单，包含：
  - `升序排列` / `降序排列` / `取消排序`
  - `按此列筛选...` (打开筛选输入框)
  - `隐藏此列`
  - `固定到左侧` / `固定到右侧`
  - `自动调整列宽` / `调整所有列宽`
* **列宽拖拽：** 表头右边缘出现 `↔` 光标，拖拽实时调整宽度。双击自动适配该列最长内容宽度。
* **列重排：** 拖拽表头中部可整列移动位置。
* **列固定 (Pinning)：** 支持将关键列（如 `id`、`_index`）固定在左侧或右侧，滚动时不随主体移动。

### 3.2 行号列 (Row Number Column)

* 表格最左侧固定显示行号列 `#`，宽度 60px，始终可见不随水平滚动消失。
* 行号使用次要文字色 (`#6B7280`)，字体 12px。
* 选中行的行号使用主色 (`#4F46E5`) 加粗显示。

### 3.3 单元格渲染规则 (Cell Rendering)

| 数据类型 | 渲染样式 | 示例 |
|----------|---------|------|
| `string` (短文本) | 默认文字，左对齐 | `hello world` |
| `string` (长文本) | 单行截断 + 省略号，Hover 显示完整 Tooltip | `A very long text th...` |
| `number` / `integer` | 右对齐，千位分隔符 | `1,234,567` |
| `boolean` | 居中显示小型 Tag 徽标：`true` 绿色 / `false` 灰色 | `● true` |
| `null` / `undefined` | 灰色斜体文字 `null`，背景微弱灰底 | *null* |
| `object` / `array` (嵌套) | 显示 `{...}` 或 `[...]` 图标徽标，蓝色调，点击展开 | `{3 fields}` |
| `Error Row` | 整行红色背景 + 左侧红色竖线 + `⚠ JSON 格式损坏` 提示 | `⚠ Invalid JSON` |
| URL 字符串 | 蓝色可点击链接样式 | `https://...` |

### 3.4 斑马纹与 Hover (Zebra Striping & Hover)

* **斑马纹：** 默认开启，奇偶行交替使用白色与极淡灰 (`#F9FAFB`) 背景，增强行可辨识度。
* **行 Hover：** 鼠标悬停行背景变为淡靛蓝 (`#EEF2FF`)，辅助视觉追踪。
* **行选中：** 点击行后背景变为靛蓝 (`#E0E7FF`)，左侧显示 3px 主色竖线指示器。
* **可选：** 支持用户在设置中关闭斑马纹，使用纯白底。

### 3.5 网格线 (Grid Lines)

* 默认显示水平网格线 (行间分隔)，不显示垂直网格线 (列间分隔) —— 这与 DataGrip / Supabase 默认行为一致。
* 水平线使用极淡灰 (`#E5E7EB`)，1px 实线。
* 用户可在设置中切换为「十字网格 (Full Grid)」或「无网格线 (No Lines)」。

## 5. 左侧 Schema 面板 (Schema Panel)

对标 DataGrip 的 Database 面板与 Supabase 的列选择器：

```
┌─────────────────────┐
│  字段 (23)    🔍     │
├─────────────────────┤
│  ☑ id          int   │
│  ☑ name        str   │
│  ☐ email       str   │
│  ☑ age         int   │
│  ☐ address     obj   │
│  │  ☑ address.city   │
│  │  ☐ address.zip    │
│  ☑ tags        arr   │
│  ☑ created_at  str   │
├─────────────────────┤
│  ▾ 排序: name ↑      │
│  ▾ 类型筛选: 全部     │
├─────────────────────┤
│  [全部显示] [全部隐藏] │
└─────────────────────┘
```

* **字段列表：** 树状展示所有扁平化后的字段，嵌套字段以缩进展示层级关系（如 `address.city`、`address.zip`）。
* **复选框控制：** 勾选/取消即时控制表格列的显示与隐藏。
* **类型标签：** 每个字段右侧显示推断出的数据类型小标签 (`str` / `int` / `bool` / `obj` / `arr`)，使用不同颜色区分。
* **搜索过滤：** 顶部搜索框快速定位字段。
* **批量操作：** 底部「全部显示」「全部隐藏」快捷按钮。
* **排序显示：** 当前列排序状态摘要（如 `排序: name ↑, age ↓`）。

## 6. 右侧详情抽屉 (Row Detail Drawer)

对标 DataGrip / DBeaver 的行编辑面板，点击表格任意行时从右侧滑入：

```
┌───────────────────────────┐
│  行详情 - #42          ✕  │
├───────────────────────────┤
│                           │
│  {                        │
│    "id": 42,              │
│    "name": "Alice",       │
│    "email": null,         │
│    "address": {           │
│      "city": "Shanghai",  │
│      "zip": "200000"      │
│    },                     │
│    "tags": [              │
│      "vip",               │
│      "active"             │
│    ],                     │
│    "created_at": "2026.." │
│  }                        │
│                           │
├───────────────────────────┤
│  [📋 复制 JSON]  [📐 格式化] │
│  [📥 复制原始行]             │
└───────────────────────────┘
```

* **JSON Tree 着色：** Key 使用蓝色、String 使用绿色、Number 使用橙色、Boolean 使用紫色、Null 使用灰色 —— 参考 VS Code 的 JSON 语法高亮配色。
* **可折叠节点：** 嵌套的 `object` 和 `array` 节点可点击 `▸` / `▾` 展开/收起。
* **操作按钮：**
  - 「复制 JSON」：复制格式化后的完整 JSON 到剪贴板。
  - 「复制原始行」：复制该行在文件中的原始 JSONL 文本。
  - 「格式化 / 压缩」：切换 JSON 展示的缩进模式。
* **滑入动画：** 从右侧以 `transform: translateX` 平滑滑入，时长 200ms，使用 `ease-out` 缓动曲线。
* **关闭方式：** 点击右上角 `✕`、按 `Esc` 键、或点击抽屉外部遮罩区域。

### 8.1 初始落地页 (Landing Page - 无文件加载时)

当用户首次打开应用，尚未加载任何文件时，展示居中的引导面板：

```
┌─────────────────────────────────────────┐
│                                         │
│            📊 JSONL Smart Viewer        │
│                                         │
│     ┌─────────────────────────────┐     │
│     │                             │     │
│     │   拖拽 JSONL 文件到此处      │     │
│     │        或                    │     │
│     │   [📂 选择文件]  [🔗 输入URL] │     │
│     │                             │     │
│     └─────────────────────────────┘     │

│     支持: .jsonl / .json / .jsonl.gz    │
│     100% 本地解析 · 隐私安全             │
│                                         │
```

* 拖拽区域使用虚线边框 (`border-dashed`)，拖入文件时边框变为主色实线 + 背景淡色高亮。

* 文件扫描阶段：显示进度条 + "正在扫描行索引... (23%)" 文字。

* 文件格式不合法：显示明确的错误提示 + "请选择 .jsonl 或 .json 文件"。
* 网络文件加载失败：显示 "无法访问远程文件" + 重试按钮。

## 9. 交互反馈与动效 (Interaction Feedback & Motion)

| 交互 | 动效 | 时长 |
|------|------|------|
| 行 Hover | 背景色过渡 | 100ms `ease` |
| 行选中 | 背景色变化 + 左侧竖线出现 | 150ms `ease-out` |
| 列排序切换 | 表头图标旋转动画 | 200ms `ease` |
| 列宽拖拽 | 实时跟随鼠标 (无延迟) | — |
| 抽屉滑入/滑出 | `translateX` 平移 | 200ms `ease-out` / 150ms `ease-in` |
| 左侧栏展开/折叠 | 宽度过渡 | 200ms `ease` |
| 筛选标签出现/消失 | `scale + opacity` 渐变 | 150ms `ease` |
| 错误行出现 | 左侧红色竖线闪烁一次 | 300ms |
| Toast 通知 | 从顶部滑入，自动消失 | 200ms 入 / 3000ms 停留 / 200ms 出 |

> **核心原则：** 所有动效时长控制在 **100ms ~ 300ms** 之间，绝不使用过长的动画干扰数据查看效率。这是开发工具与消费级应用的核心区别 —— **效率优先，花哨其次**。

## 10. 键盘快捷键 (Keyboard Shortcuts)

对标 DataGrip / DBeaver 的键盘导航习惯：

| 快捷键 | 功能 |
|--------|------|
| `↑` / `↓` | 上下移动选中行 |
| `←` / `→` | 水平滚动表格 (或切换焦点单元格) |
| `Enter` | 打开当前行的右侧详情抽屉 |
| `Esc` | 关闭抽屉 / 取消搜索 / 取消筛选 |
| `Cmd/Ctrl + F` | 聚焦全局搜索框 |

## 11. 响应式与边界处理 (Responsive & Edge Cases)

* **最小视口：** 支持 1024×768 最小分辨率，低于此宽度时左侧栏自动折叠为图标模式。
* **超宽屏：** 表格列自动填满可用空间，右侧留白不超过一列宽度。
* **超多列 (100+ 列)：** 性能不受影响（虚拟化仅渲染可见列）；左侧栏默认折叠嵌套字段。
* **超长字段值：** 单元格内单行截断，Tooltip 最大宽度 400px，超长内容在 Tooltip 内换行展示。
* **空单元格：** 显示灰色斜体 `null`，而不是空白 —— 空白无法区分「无数据」和「未加载」。

## 12. 无障碍 (Accessibility)

* 所有交互元素支持键盘 Tab 聚焦，Focus 状态显示可见的主色描边轮廓。
* 表格使用语义化 `<table>` 或 `role="grid"` + `aria-*` 属性。
* 行选中状态通过 `aria-selected` 暴露给屏幕阅读器。
* 颜色对比度符合 WCAG 2.1 AA 标准 (最低 4.5:1)。
* 支持通过 `prefers-reduced-motion` 媒体查询关闭所有非功能性动画。
